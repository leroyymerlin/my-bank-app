# ELK Stack

Этот подпроект содержит конфигурационные файлы для ELK стека (Elasticsearch, Logstash, Kibana) и Filebeat для сбора, хранения, обработки и анализа логов микросервисов.
### Elasticsearch

- Хранение логов микросервисов
- Полнотекстовый поиск
- Агрегации и аналитика

### Logstash

- Сбор логов из микросервисов через TCP/UDP
- Обработка и фильтрация логов
- Маскирование чувствительных данных (логины, балансы, суммы)
- Отправка в Elasticsearch

### Kibana

- Визуализация логов
- Поиск и анализ
- Создание дашбордов

### Filebeat

- Сбор логов с Docker контейнеров
- Отправка в Logstash

### Loki (для Grafana)

- Хранение логов
- Интеграция с Grafana
- Запросы логов через LogQL

## Настройка Logstash Pipeline

Logstash настроен на сбор логов из следующих источников:

1. **TCP (port 5000)** - отправка логов из микросервисов
2. **UDP (port 5001)** - альтернативный способ отправки логов
3. **File** - чтение логов Frontend UI

## Использование

### Запуск через Docker Compose

```bash
# Запуск всех сервисов
docker-compose up -d

# Доступ к Kibana
http://localhost:5601

# Доступ к Elasticsearch
http://localhost:9200

# Доступ к Loki (для Grafana)
http://localhost:3100
```
